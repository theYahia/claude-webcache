## ✅ Сделано (federation MVP — снимает Non-goal «Not multi-machine»)
- **`plugin/src/federation.js`** — pure-stdlib federation client: `parsePeers`, `fetchFromPeers(url, prompt, peers, {token, timeoutMs})`. Ключевая схема = `SHA256(namespace|canonUrl|prompt)` — **байт-в-байт совпадает с cache.js**, поэтому значение, закэшенное инстансом A, находится инстансом B (cross-instance hit проверен).
- **`plugin/scripts/federation-server.cjs`** — ОТДЕЛЬНЫЙ процесс (как dashboard), отдаёт read-only cache lookups по HTTP (`/federation/get`, `/federation/health`). Loopback по умолчанию; опц. shared-secret `WEBCACHE_FEDERATION_TOKEN` (timing-safe). MCP остался **stdio-pure** (federation.js — только HTTP-client, 0 listeners при импорте — проверено).
- `mcp-server.cjs`: на локальном miss → опрос пиров (`WEBCACHE_PEERS`), peer-hit пишется в локальный кэш; tool `cache_federation_stats`.
- **FAIL-OPEN доказан на 3 уровнях** (unit / integration / против реального federation-server): любой peer down/500/timeout/garbage → `null`, никогда не throws; поведение идентично «нет пиров». 8MB cap на ответ пира (анти-OOM).
- **0 новых npm-зависимостей** (pure Node stdlib). Версия **0.7.0** консистентна (package.json + plugin.json + marketplace.json + lock).
- Тесты: **16/16 federation** + существующие e2e 5/5. Re-publish PREP готов (CHANGELOG + README federation-секция). Adversarially verified (verdict solid).
